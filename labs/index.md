# Labs

A place to try things. Each lab has its own workbench; choose the experiment you want to explore.

For the guided curriculum, head to [Courses](/courses/). These labs are side experiments, not required lessons.

{widget lab-cards}

Opening a lab does not download a model. Live experiments load only when you ask them to; hardware, memory and browser settings affect the results.
