In this month's [GroovyMag](http://groovymag.com) I talk about sharing a database between a J2EE application and a Grails application that is using GORM. If you haven't spent anytime working with concurrency in database applications you will really want to check this out. If you have a Container Managed Persistence (CMP) application that you are working with and you have a green-light on using [Grails](http://grails.org) you might consider moving directly from EJB2 to GORM in a phased manner sharing parts of the database on the way.
