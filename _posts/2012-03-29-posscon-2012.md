I had a great time at [POSSCON 2012](http://posscon.org), met up with [Steve Graham](http://www.posscon.org/speaker/steve-graham/) (a fellow Triangle Resident), got to talk to [Jon 'Maddog' Hall](http://www.posscon.org/speaker/jon-maddog-hall/), and a whole host of Open Source luminaries. I even learned what a [Palmetto](http://en.wikipedia.org/wiki/Palmetto) is. My talk was [An Introduction to Grails](http://www.posscon.org/presentation/intro-to-grails/) where in I live code while explaining each line. The source code is up on [github](https://github.com/hartsock/glinkulator) now if you want. The slides are naturally available below:  POSSCON is definitely a conference you should check out.
