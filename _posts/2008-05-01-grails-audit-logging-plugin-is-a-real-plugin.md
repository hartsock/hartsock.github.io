I'm very happy to be able to post that the [Audit Logging Plugin](http://grails.org/Grails+Audit+Logging+Plugin) is now available via the "official" Grails plugin install commands. My plugin is no where near as cool as the [Searchable Plugin](http://grails.codehaus.org/Searchable+Plugin) but I'm very pleased to offer it up. I hope it fills a need judging from the relatively large spike in traffic I got from other blogs and sites like [refactr](http://refactr.com/blog/2008/04/grails-audit-logging-plugin/) I'd say there's quite a few people who might want this plugin.

You know who you are. Now you can send me bug reports!
