I honestly thought I'd be talking about how great Searchable is *going* to be for at least another six months... [and then](http://aboutgroovy.com/item/show/419) this happened: [Searchable Plugin: Just use it!](http://dave-klein.blogspot.com/2008/04/searchable-plugin-just-use-it.html). It literally *just works*. **WOW!** I'm so happy right now I think I need to dance!

I downloaded the new searchable plugin and installed it into my latest Grails project. Suddenly I can start using search on all my properly configured domain classes. I immediately added a search bar to my application even though it's not in the requirements.

This is a fantastic win for Grails. I am so shocked we have a version that works so well so soon. Honestly, start using [Grails](http://grails.org/) *now* just so you can use this [plugin](http://grails.org/Searchable+Plugin). Go! Do it now! Go!
